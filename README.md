## 📌 Executive Summary

**LOOP** is a production-style, enterprise-ready **AI Customer-Feedback Intelligence Platform** built on the MERN stack. It ingests unstructured customer feedback across multiple channels (*Support Tickets, App Store Reviews, NPS Surveys, Sales Calls, Community Posts, CSV Uploads*), automatically categorizes sentiment and themes, and enables team members to ask grounded natural language questions using **Hybrid Vector + Lexical RAG (Retrieval-Augmented Generation)**.

Every answer generated by LOOP is **100% grounded in verified customer feedback evidence**, eliminating AI hallucinations with automated refusal guardrails and supporting quotes.

## 🚀 Key Features & Capabilities

### 🔐 1. Multi-Tenant Workspace & Role-Based Access Control (RBAC)
* **Tenant Isolation**: All queries enforce `{ workspaceId }` derived strictly from authenticated JWT tokens.
* **Granular Role Hierarchy**:
  * 👑 **Admin**: Full access — CRUD feedback, CSV import, AI reclassification, VoC reports, workspace management, record deletion.
  * 📊 **Analyst**: Feedback submission, CSV import, AI classification, Ask LOOP Q&A, VoC report generation.
  * 👁️ **Viewer**: Read-only view (mutations return **HTTP 403 Forbidden** server-side).

### 🤖 2. Automated AI Classification Pipeline
* **Sentiment Analysis**: Classifies text as `Positive (POS)`, `Neutral (NEU)`, or `Negative (NEG)` with floating score ($-1.0$ to $+1.0$).
* **Theme & Feature Area Extraction**: Categorizes feedback across 11 core themes (*Onboarding, Billing, Performance, Mobile Experience, Authentication, Exports, Notifications, Integrations, Pricing, Support, Dashboard*) and assigns specific feature tags.
* **AI Rationale**: Generates a concise sentence explaining the classification logic.

### 🧠 3. Grounded Hybrid RAG Intelligence (Ask LOOP)
* **Local Pretrained Sentence Vectorization**: Converts feedback into 384-dimensional dense vectors using `@xenova/transformers` (`Xenova/all-MiniLM-L6-v2`) locally in Node.js.
* **70/30 Hybrid Search**: Fuses $70\%$ vector cosine similarity $+ 30\%$ TF-IDF lexical keyword matching.
* **Refusal Guardrail**: Queries with hybrid similarity $< 0.18$ trigger an automatic refusal (*"I couldn't find enough customer feedback to answer that question"*), preventing hallucinations.
* **3-Tier AI Fallback Cascade**:
  1. *Primary*: Anthropic Claude API (`claude-sonnet-4-6`)
  2. *Free Fallback 1*: Google Gemini 1.5 Flash API (`GEMINI_API_KEY`)
  3. *Free Fallback 2*: Smart Local Grounded Synthesis Engine ($0 cost, 100% offline ready)

### 📥 4. Robust Native CSV Import
* Ingests external feedback CSV files with stream validation, MIME type checks, and 5MB file limits.
* Automatically triggers 384-dimensional vector embedding generation and background AI classification for all imported rows.
* Includes 4 pre-built realistic CSV sample datasets (*Onboarding, Billing, App Store Reviews, Support Tickets*).

### 📊 5. Analytics Dashboard & VoC Reports
* **Interactive Data Visualizations**: Recharts Area Charts (Volume over time), Pie Charts (Sentiment distribution), and Bar Charts (Themes).
* **Spike Detection**: Automatically flags themes with $\ge 50\%$ increase in negative sentiment.
* **Voice-of-Customer (VoC) Executive Reports**: MongoDB pre-computes sentiment stats and theme counts, and the LLM synthesizes an executive Markdown narrative. Includes one-click PDF print export (`window.print()`).

## 💻 Installation & Setup Guide

### 1. Prerequisites
* **Node.js** v18.0 or higher
* **MongoDB** (Local instance or MongoDB Atlas Cloud URI)

### 2. Clone the Repository
```bash
git clone https://github.com/jasinthashankar/Loop-project-Zidio.git
cd Loop-project-Zidio
```

### 3. Server Setup & Environment Configuration
Navigate to the `server/` directory and install dependencies:
```bash
cd server
npm install
```

Create a `.env` file inside `server/` (copy from `.env.example`):
```env
PORT=5000

# MongoDB Atlas Cloud (or use mongodb://127.0.0.1:27017/loop for local dev)
MONGO_URI=mongodb+srv://<db_user>:<db_password>@<cluster>.mongodb.net/loop?retryWrites=true&w=majority

JWT_SECRET=your_jwt_secret_here_make_it_long_and_random

# PRIMARY AI: Anthropic Claude (paid)
# Get key at: https://console.anthropic.com/
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-sonnet-4-6

# FREE AI FALLBACK: Google Gemini 1.5 Flash
# Get FREE key at: https://aistudio.google.com/app/apikey
GEMINI_API_KEY=AIzaSy...

# If both AI keys are unavailable, the Local Grounded Synthesis Engine
# activates automatically — no key needed, works 100% offline.

CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

### 4. Seed the Database
Populate your database with demo users, workspace, 132+ customer feedback records, themes, and 384-dim pretrained vectors:
```bash
npm run seed
```

### 5. Client Setup
Open a new terminal window, navigate to `client/`, and install dependencies:
```bash
cd client
npm install
```
